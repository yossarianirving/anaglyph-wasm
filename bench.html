Gif → anaglyph: WebGPU vs CPU

Each gif is converted repeatedly through both paths of the same wasm build: gif_to_anaglyph_async (WebGPU compute shader, CPU fallback if unavailable) and gif_to_anaglyph_cpu (blocking single-threaded CPU loop). Runs are interleaved; one warmup run per path is discarded. Note the encoding pass (gif decode + encode) runs on the CPU in both paths; only frame blending differs.
